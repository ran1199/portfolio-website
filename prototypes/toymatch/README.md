# ToyMatch prototypes (Product Management Essentials)

Interactive iPhone app prototypes for ToyMatch. They are school work, separate from the
portfolio website: nothing in `prototypes/` is published on the portfolio site.

| Folder | Version | Status |
|---|---|---|
| `concept-1/` | ToyMatch — Concept 1 | Frozen. Don't edit; copy it to start a new concept. |

**Preview:** open `concept-1/index.html` in Safari or Chrome. On a computer it shows an
iPhone frame; on a phone it fills the screen. A private preview page is also on claude.ai
(link in the session notes).

**Snapshot:** Git tag `toymatch-concept-1` marks this exact version.

**Starting Concept 2:** copy `concept-1/` to `concept-2/` and change only the copy, so both
versions stay available to compare.

All toys, makers, retailers, prices, ratings, review summaries, stock and delivery
information in these prototypes are invented sample data.
